# unguarded endpoint gets past the build, and it should be rare enough to
# be argued for. Removing one - by adding check.permission - is the point.
#
# The strongest evidence this is unfinished rather than intended is that
# modules are split: hr has 125 guarded and 120 not, and within it
# hr/departments is gated while hr/off-cycle-payroll is not.
