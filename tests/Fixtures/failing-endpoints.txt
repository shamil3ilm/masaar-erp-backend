# Endpoints that answer 5xx to a request they should be able to refuse.
#
# RouteSmokeTest calls every endpoint it can reach — every parameterless GET,
# every GET by an id that matches no row, and every write with no body — as a
# user holding the whole permission catalogue. None of them should fail; a
# 4xx is an answer, a stack trace is not.
#
# A ratchet, not an approval. Nothing may be added without a reason written
# beside it, and an entry that no longer fails must be removed: the test says
# so, so that the next regression cannot hide behind a stale line.
#
# The list is empty, on SQLite and on MySQL. The one entry it used to hold was
# the TDS pending report, which queried a status column that neither
# tds_deductions nor either of its two models had. It went with the India
# module.
