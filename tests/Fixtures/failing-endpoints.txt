# 238 by an id that matches no row, and 1,011 writes with no body — as a user
# holding the whole permission catalogue. None of them should fail; a 4xx is an
# answer, a stack trace is not.
#
# A ratchet, not an approval. The set may shrink and may not grow.

# runs on in-memory SQLite. These are believed to work in production and are
# tested nowhere: CI has no MySQL job, so nothing here or in the pipeline ever
# executes this SQL. Rewriting the raw SQL as a driver-agnostic expression
# would move them out of this file and under test.
