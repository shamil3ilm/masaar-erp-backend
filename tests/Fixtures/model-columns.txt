# Models declaring an attribute that no column backs.
#
# Each line is a model, its table, and the attributes it lists in $fillable or
# $casts that the table does not have.
#
# These are not typos in the main. They are designs that were half migrated:
# the model describes the feature that was intended and the migration describes
# what was built. Writing such an attribute is an error on MySQL; reading one
# gives null; filtering by one on SQLite silently matches nothing rather than
# failing, which is why the suite never noticed.
#
# Every model's attributes have a column, so this list is empty. A ratchet:
# it may not grow, and a model naming a missing column fails the test.
