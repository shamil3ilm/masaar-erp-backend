# Queries naming a column the table does not have.
#
# Every one of these filters on something that is not there. SQLite reads an
# unknown quoted identifier as a string rather than failing, so the clause
# matches nothing and the caller is told there is no data. MySQL raises. Two
# scheduled commands sat in this state until CI ran them against MySQL —
# cleaning up no sessions, and running no reports whatever was scheduled.
#
# This check is static, so it finds them without the code having to run, which
# is the only way to see the ones nothing calls.
#
# It only judges the where family. SQL cannot reference a select alias in a
# WHERE, so a name there must be a column. orderBy, groupBy and pluck are not
# checked, because selectRaw('COUNT(*) as cnt')->orderBy('cnt') is correct and
# looks identical to a mistake. Chains containing a join, union or whereHas are
# skipped, since a bare name may belong to the other table, and qualified
# names are skipped for the same reason.
#
# Spot-checked against the schema: employees has employment_status and no
# status, chart_of_accounts has account_type and no type, user_sessions has
# neither token_id nor expires_at.
#
# What is left is the India tax module, which is parked, and the dead
# UserLifecycleService session methods nothing calls.
#
# A ratchet, not an approval. The list may shrink and may not grow, and the
# test fails if an entry here has been fixed and not removed.
